# NotaProgramming-Pro's Official Operating System Archive

This repository serves as an archival and preservation record for the Scratch project "NotaProgramming-Pro's Official Operating System" by [NotaProgramming-Pro](https://scratch.mit.edu/users/Notaprogramming-pro/).

This archive is maintained for historical reference, documentation, and preservation. It is not intended to claim authorship of the original project. The original creator is credited here as stated by the project itself.

## Project Summary

According to the creator's instructions and notes, "NotaProgramming-Pro's Official Operating System" is a large, ongoing Scratch-based operating system project designed to simulate a desktop-style environment within Scratch. It includes a terminal interface, file system tools, GUI elements, browser-style navigation, simulated apps, settings, performance features, and a long development roadmap.

The project description states that it is a work in progress and that it is intended to improve over time, with updates planned periodically.

## Project Instructions (as provided by the creator)

The creator states:

> "This is a work in progress and will get better over the span of several months. I plan to drop updates about once per 2 weeks. Eventually, I will stop making other projects entirely and just make the projects in the operating system."

The project also includes update notes describing the development progression of the system, including early file and command features, GUI access, browser integration, system specs, boot sequence, app store, sound effects, and mobile support improvements.

## Update History (as stated by the creator)

### Alpha updates
- Alpha 0.0.1: Initial launch; ability to create .txt files; added read_drive command
- Alpha 0.0.2: Additional commands; interface auto-scroll improved
- Alpha 0.0.3: More commands; first screen animations
- Alpha 0.0.4: Added /GUI command; built-in drive reader and system access tools
- Alpha 1.0.0: Interface remake to simplify opening the GUI
- Alpha 1.1.0: Browser icon added; future support for GUI/text file access; settings for TurboWarp and turbo mode
- Alpha 1.1.1: Added calculator.surf website; /close universal command introduced
- Alpha 1.1.2: Added Specs menu
- Alpha 1.1.3: Added bootup sequence and intro

### Beta updates
- Beta 1.0.0: Added app store
- Beta 1.1.0: Added spec monitor for supported hardware
- Beta 1.1.1: Faster boot sequence
- Beta 1.1.2: Bug fixes; mouse support added
- Beta 1.1.3: Mouse support improved for mobile-friendly use
- Beta 1.1.4: New icons; mobile support refined
- Beta 1.1.5: Graphic overhaul; Games app added on the app store
- Beta 1.1.6: Sound effects added; startup sound and keyboard/mouse click sounds included
